# HW2 Part 3 — Ben Kettor

HTML-only replication of the supplied fictional coffee research article.
Source: https://github.com/EthanLDot/cse134b_hw2_starter

Open index.html in your browser. Deploy this folder as a NEW Netlify project, separate from Part 2. Leave the build command empty and use . as the publish directory.

No JavaScript. The only CSS sets table-column widths, expressly permitted by the starter README. Native details is initially closed. Buttons are placeholders. Original supplied starbucks.jpg is used at 400 by 300. Fictional authors and research are preserved from the assignment; they are not Ben's claims.

Validation: official Nu HTML Checker 26.10.12 reports zero messages. The online validator endpoint returned HTTP 429 during the pre-deployment check; validate the live URL after deployment. All 33 required Part 3 tags are present.
